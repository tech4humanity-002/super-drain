# Super Drain privacy notice

Super Drain can run locally or in the cloud.

## Local use

The core analysis can run in your browser. Working data is stored in browser-local storage and is not sent to the Super Drain collection service when product-improvement collection is OFF.

## Product-improvement collection

When the collection setting is ON, submitted material and analysis results may be sent to the Super Drain product-improvement collection service.

The purpose is product review, quality improvement and understanding how people use the tool.

The collection may include:

- source names and source types
- submitted text and extracted occurrences
- URLs supplied to the tool
- analysis results
- evidence hashes and receipts
- browser and application metadata needed to operate the collection service

The service does not require a Tech 4 Humanity customer account or an AI API key.

Turn collection OFF before submitting confidential or sensitive material that you do not want retained.
